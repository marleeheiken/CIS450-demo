### How Edge Detection works 
-  Edge detection is used to identify sharp changes in brightness that typically signify object edges, lines, or even textures like in the Mona Lisa painting example we used. Edges are detected mathematically using gradients, which measure changes in pixel intencity.


### Learning to use GitHub Copilot 
#### Call Sequence:  plt.plot -> gca().plot -> Axes.plot -> add_line

- `plt.plot` - calls gca().plot and returns the list of created Line2D objects
- `gca().plot` - calls Axes.plt
- `Axes.plot` - draws lines/markers for one or more (x,y) datasets and returns a list of Line2D objects
- `add_line` - adds a Line2D artist to the axes and integrates it into the axes state
